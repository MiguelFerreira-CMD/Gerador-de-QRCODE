# Gerador de QR Code

Projeto desenvolvido em **Python** para gerar QR Codes a partir de links ou textos.

O projeto foi criado como um exercício prático de aprendizado, com foco no uso de **bibliotecas Python**, geração de imagens e automação de tarefas simples.

## Sobre o projeto

O programa utiliza a biblioteca `qrcode` para transformar um link ou texto em um QR Code e salvar o resultado como uma imagem `.png`.

Atualmente, o projeto gera um QR Code direcionado ao meu perfil no GitHub.

## 🛠️ Tecnologias utilizadas

* 🐍 Python
* `qrcode`
* `Pillow`

## 📦 Bibliotecas

Para instalar as dependências, execute:

```bash
pip install qrcode pillow
```
